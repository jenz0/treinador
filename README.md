# Treinador · Poképedia pessoal (projeto pessoal, não oficial)

App web instalável: Poképedia de todas as gerações, parties fictícias e contexto opcional de jogo (FireRed, LeafGreen, Ruby, Sapphire, Emerald, Pokémon Unbound 2.1.1.1).

Publicação no GitHub Pages: envie todos os arquivos desta pasta para a raiz de um repositório público e ative *Settings → Pages → Deploy from a branch → main / (root)*.

Fontes dos dados: Skeli789/Dynamic-Pokemon-Expansion (branch Unbound), Skeli789/Complete-Fire-Red-Upgrade, PokéAPI (CSV) e @pkmn/dex (dados do Pokémon Showdown).
Pokémon é marca da Nintendo/Game Freak/The Pokémon Company; este projeto não tem relação com elas.
